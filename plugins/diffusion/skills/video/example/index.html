This pull request retries webhook deliveriesthat fail with a server error.
Why
One 502 from a merchant dropped the event for good
Merchants rebuilt state by polling every minute
Today a single bad gateway drops the event,so merchants poll to catch up.
webhooks/deliver.rs
match send(&hook, &event).await {
Err(e) => return Err(e),
Err(e) if e.is_server() => queue.retry(event, backoff(n)),
Err(e) => return Err(e),
Ok(_) => Ok(()),
}
Server errors now go back on the queue with a backoff,while client errors still fail right away.
